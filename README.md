## 🌍 About This Project

Forensic Eye Botswana is the first private digital forensics and cybersecurity firm in Botswana. This repository is our contribution to the African open-source security ecosystem — providing free, practical tools, guides, and frameworks that empower:

- 🏢 **African SMEs** to defend against cyber threats
- 🏛️ **Law enforcement agencies** with digital forensics methodologies
- 🎓 **Students and researchers** in cybersecurity across the African continent
- 🛡️ **IT professionals** with incident response playbooks

## 📦 What's Inside

### 1. `incident-response/`
Step-by-step incident response playbooks tailored for African SMEs and organisations, covering:
- Ransomware response
- Phishing incident handling
- Mobile device compromise
- Financial fraud (Orange Money, MyZaka, BURS-themed phishing)

### 2. `mobile-forensics/`
Guides and checklists for mobile device forensic acquisition:
- Android forensics workflow
- SIM card evidence preservation
- WhatsApp and social media data recovery methodology
- Chain of custody documentation templates

### 3. `network-forensics/`
Network intrusion analysis resources:
- Packet capture analysis guides (Wireshark)
- Network log review checklists
- Common African ISP traffic patterns and anomaly detection
- Botswana-specific threat intelligence notes

### 4. `awareness-training/`
Free cybersecurity awareness materials for African organisations:
- SME cyber hygiene checklist (English & Setswana)
- Phishing simulation guide
- Social engineering awareness poster templates
- "Anatomy of a Cyberattack" visual explainer

### 5. `legal-frameworks/`
Digital evidence documentation templates aligned with Botswana legal standards:
- Chain of custody forms
- Digital evidence seizure logs
- Expert witness statement templates
- Cybercrime Act of Botswana (2007) reference summary

### 6. `tools/`
Lightweight open-source scripts and utilities:
- `hash_verify.py` — File hash verification for evidence integrity
- `metadata_extractor.py` — Document and image metadata extraction
- `log_parser.py` — Basic Windows/Linux log parsing for investigations

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/charlesnyamudzanga/forensic-eye-botswana-toolkit.git

# Navigate to the toolkit
cd forensic-eye-botswana-toolkit

# Install Python dependencies (for scripts)
pip install -r requirements.txt
```

## 🌐 Why This Matters for Africa

Botswana and many African nations face a critical gap: **no established private digital forensics infrastructure**. When cybercrime occurs, organisations have limited resources and expertise to respond effectively.

This toolkit addresses:
- **The skills gap** — Free, practical training materials
- **The tools gap** — Lightweight scripts that work on low-resource systems
- **The legal gap** — Documentation templates aligned with African legal contexts
- **The language gap** — Materials in English and Setswana

Forensic Eye Botswana built this because **Africa's cybersecurity future depends on Africans building it.**
