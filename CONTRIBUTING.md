# Contributing to Forensic Eye Botswana Toolkit

Thank you for your interest in contributing to this project.
Forensic Eye Botswana welcomes contributions from the African
security community and global cybersecurity professionals.

## How to Contribute

### Reporting Issues
- Open an issue describing the bug or suggestion
- Include your operating system and Python version
- Be as specific as possible

### Submitting Changes
1. Fork the repository
2. Create a new branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Commit with a clear message (`git commit -m 'Add: description'`)
5. Push and open a Pull Request

## What We Need

- Incident response playbooks for African SME scenarios
- Mobile forensics guides (Android focus)
- Setswana language translations of awareness materials
- SADC region threat intelligence contributions
- Testing of existing Python tools across environments

## Code Standards

- Python 3.8+ compatible
- Include comments explaining forensic significance
- Follow existing file structure
